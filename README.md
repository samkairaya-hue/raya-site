# Raya

Attached is a website design in both PDF and HTML formats. 




Provide a password protected content management system (CMS)




All texts and photos in the design should be replaceable by a CMS. Text should be provided in plain text. The design (font, size, color, style) should be taken from the attached design documents. 




Please note that the text to be replaced might be longer or shorter. The HTML design should allow keeping the layout even though the text will be longer or shorter. In extreme cases, the design should use 3 dots “(continue ..)” to expand for more reading. The Hebrew form “(להמשך …)”. 




Attached is also a design document in PDF format with marks on text for example to be extracted to the CMS. Please note that the buttons text should also be editable. The icons are part of the design and shouldn’t be editable. 




Color palette should be editable from the CMS. 




The button on the first page should lead to the last page (the contact us page that starts with “בוא/י נפרק את הלופ ונחזיר את השקט לחיים”). 




All squares in pages 3, 5 and 6 will also have in the CMS input fields to the page that will be presented after they are clicked. The design of the target pages should be in the same look and feel. If no text was provided, the related square won’t be clickable. The input fields should be arranged in collapsible panels in the CMS. Please note that the squares from pages 3 and 5 lead to a different design than the squares of page 6. 




Page 8 contains FAQ. Please allow add and remove FAQs. Each FAQ is a collapsible panel. Only maximum of 1 expended at a time. The only expended one can be collapsed. Allow reordering of the FAQ from the CMS. 




The button at the 9th page (contact us) should send and email to the admin address (should be configurable from the CMS). The subject of the email should be “פניה באתר: “ followed by the first name provided at the form (the first field). The email content should contain the text provided at the 2nd and 3rd fields. 




After a successful delivery of a message to the admin, the text of the button should be changed to an alternate text (also provided through the CMS on the same location where the main text is provided) and the color of the button should be changed to green and the form should be reset (get empty). After 3sec the button should get back to his original color and text.
